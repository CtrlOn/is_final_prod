# Vizualizacija

## Simuliacija

- Dalelės stumia viena kitą
- Ryšiai jas traukia tarpusavy
- Daleles (silpnai) traukia centras

## Representacija

- Dalelės - autoriai
- Ryšiai - bendros kopublikacijos
  - publikacijų įtaka nepriklauso nuo autorių kiekio
- Spalvos - institutai
  - Gali turėti kelias spalvas (Beach ball layout)
- Dydis - publikacijų skaičius R = (4 + sqrt(pubs))
